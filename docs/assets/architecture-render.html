Flask UI

User Enters Journey

Start and destination are submitted through the map search form.

External APIs

Geocoding and Optional Traffic

OpenRouteService resolves typed locations. TomTom can provide traffic labels when configured.

bus.xlsx

Bus Stop Dataset

Routes, stop names, GPS coordinates, services, and stop order are loaded with Pandas.

Graph

Nodes and Weighted Edges

Bus stops become nodes. Bus links and nearby walking transfers become weighted graph edges.

Nearest Stop

Match Start and End Stops

The app finds the closest known bus stops to the requested start and destination.

A* Search

Shortest Route Calculation

A* searches the graph, then post-processing identifies bus services, transfers, and walks.

Folium / Leaflet

Interactive Map Result

Markers, bus route lines, walking segments, distance, time, traffic, and directions are rendered.

App Features

Accounts, History and Sharing

Users can save recent searches. Admins can test disruptions. Telegram sharing is optional.

Demo mode uses exact bus stop names, in-memory accounts/search history, local route geometry, and no external API side effects.
